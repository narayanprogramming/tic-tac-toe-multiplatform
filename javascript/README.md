
# 🌐 Tic Tac Toe – JavaScript Edition

## 📌 Overview
Tic Tac Toe – JavaScript Edition is a browser-based implementation of the classic Tic Tac Toe game developed using HTML, CSS, and JavaScript. The project demonstrates frontend web development concepts, dynamic user interaction, and game logic implementation through an intuitive and responsive interface.

## ✨ Features
- 🎮 Player vs Player Gameplay
- 🏆 Automatic Winner Detection
- 🤝 Draw Detection
- 🔄 Restart Game
- ⚡ Real-Time Move Validation
- 🎨 Responsive & Interactive UI

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

JavaScript/

## 🚀 Installation
1. Clone this repository.
2. Open the project folder.
3. Run `index.html` in any modern web browser.
