# ☕ Tic Tac Toe – Java Edition

## 📌 Overview
Tic Tac Toe – Java Edition is a desktop-based implementation of the classic Tic Tac Toe game developed using Java. The project demonstrates Object-Oriented Programming (OOP), event-driven programming, and Java GUI development while providing an interactive and user-friendly gaming experience.

## ✨ Features
- 🎮 Player vs Player Mode
- 🤖 AI Mode (if implemented)
- 🏆 Automatic Winner Detection
- 🤝 Draw Detection
- 🔄 Game Reset
- 🖥️ Interactive GUI
- ⚡ Real-Time Move Validation

## 🛠️ Technologies Used
- Java
- Java Swing / AWT
- Object-Oriented Programming (OOP)
