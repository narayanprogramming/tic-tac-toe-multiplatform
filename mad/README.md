# 📱 Tic Tac Toe – Mobile Application Development (MAD)

## 📌 Overview
Tic Tac Toe – MAD is an Android application developed as part of the Mobile Application Development course. The project implements the classic Tic Tac Toe game with an intuitive user interface, responsive gameplay, and efficient game logic to demonstrate Android development concepts using Java.

## ✨ Features
- 🎮 Player vs Player Mode
- 🤖 AI Mode (if implemented)
- 🏆 Winner & Draw Detection
- 🔄 Restart Game
- 📱 Responsive Android UI
- ⚡ Real-Time Move Validation

## 🛠️ Technologies Used
- Java
- Android Studio
- Android SDK
- XML
- Object-Oriented Programming (OOP)

## 🚀 Installation
1. Clone this repository.
2. Open the project in Android Studio.
3. Sync Gradle files.
4. Build and run the application on an emulator or Android device.
