
# 🐘 Tic Tac Toe – PHP Edition

## 📌 Overview
Tic Tac Toe – PHP Edition is a web-based implementation of the classic Tic Tac Toe game developed using PHP, HTML, CSS, and JavaScript. The project demonstrates backend web development concepts, server-side scripting, game logic implementation, and interactive user interface design while providing a seamless gaming experience.

## ✨ Features
- 🎮 Player vs Player Gameplay
- 🌐 Web-Based Interface
- 🏆 Automatic Winner Detection
- 🤝 Draw Detection
- 🔄 Restart Game
- ⚡ Real-Time Move Validation
- 🎨 Responsive User Interface

## 🛠️ Technologies Used
- PHP
- HTML5
- CSS3
- JavaScript
- XAMPP

## 🚀 Installation
1. Clone this repository.
2. Copy the project folder to the **htdocs** directory in XAMPP.
3. Start **Apache** from the XAMPP Control Panel.
4. Open your browser and navigate to:
   ```
   http://localhost/project-folder/
   ```
5. Start playing the game.
