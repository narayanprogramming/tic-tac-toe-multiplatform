# 🎮 Tic Tac Toe – Multi-Platform Game Development

A comprehensive Tic Tac Toe game developed across multiple platforms and programming languages, demonstrating desktop, web, and mobile application development. This repository showcases the implementation of the same game using **Java, HTML/CSS/JavaScript, PHP, and Android**, highlighting software engineering principles, Object-Oriented Programming (OOP), and cross-platform application development.

---

## 📌 Project Overview

This project was developed as part of academic learning to strengthen programming fundamentals, software design, and application development skills. Each implementation focuses on providing an interactive gaming experience while exploring different technologies, programming paradigms, and development environments.

The repository contains complete source code, project reports, documentation, and supporting resources for each version of the Tic Tac Toe game.
